GameShark Codes

This page is just being started. There will be many more codes added later.

1 • Built-In Codes

These codes come with the GameShark Pro 3.30. Codes are listed in the same order they are presented in the GameShark's menu. Some of these work on the GE/PD Edition emulator and some don't. It's kind of a toss-up.

1.1 No Backgrounds

Code
8003 6F7B 0000

Turns off level geometry. Only objects such as characters, breakable glass, props, and vehicles are rendered.

1.2 No Objects

Code
8003 6F7F 0000

Turns off objects, effectively making guards invisible. Not even their weapons or hats will render.

1.3 Walk Through Doors

Code
8003 64CB 0000

Turns off object collision, allowing you to walk through doors and other objects.

1.4 Enable All Levels

Code
8003 6FB7 0001

Unlocks all levels on all difficulties even in a brand new save file.

1.5 Have All Objectives Done

Code
8003 6FD3 0001

Completes all objectives as soon as the level starts. On Egyptian this means you cannot play the level because it switches to the outro cinema as soon as the level is loaded.

1.6 Extra Ammo

Code
8003 0B28 0048

Weapons provide the maximum ammo of its type when collected. For example if you pick up a KF7 instead of getting 10 rounds, you get 400 rounds.

1.7 Bulletproof Bond

Code
8002 CE44 0030 8003 0B20 0030

Bond still gets hit by guards' firearms, but they do no damage. Explosives and drone guns still do regular damage. Functionally the same as setting enemy damage to 0% in 007 Mode.

1.8 Enemy Cannot Aim

Code
8002 CE40 0030 8003 0B1C 0030

Enemies never hit Bond. Functionally the same as setting enemy accuracy to 0% in 007 Mode.

1.9 Weak Enemies

Code
8002 CE48 0048

Enemies die in one hit to any part of the body from any gun. Functionally the same as setting enemy health to 0% in 007 Mode.

1.10 Extra Characters

Code
8002 B197 0040

Unlocks all characters in multiplayer including the hidden ones normally only accessible via this button code.

2 • Debug Cheats

2.1 Debug Menu

Code
81036F6C 0000 81036F6E 0002 D0064F31 000C 80024303 0001

This code brings up the Debug Menu. Once the game is started with the code activated press + at the same time to bring up the Debug Menu.
