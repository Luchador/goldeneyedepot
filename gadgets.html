Gadgets

Goldeneye 007 was one of the first FPS games to make use of gadgets, especially as mission-critical tools. Of course these gadgets are provided by the legendary 'Q' of MI6.

Plastique

Infinite Use
No
Max Capacity
11
Location
Silo
Explosive gadget with "C4" written on top and sides.

From the Instruction Booklet

Name
Plastique
Description
A shaped-charged plastic explosive with a timer setting.

This gadget is issued to the player in Silo for destroying the entire launch complex. It has an automatic timer, but will also explode if shot. If it goes off early you will perish very quickly. If you have invincibility on a series of explosions with follow you around, destroying everything around you.

This model is reused in Frigate as a prop for the bridge and engine bombs. Detonating these bombs won't blow up the whole level like it does with Silo.

Door Decoder

Infinite Use
Yes
Location
Facility
Gadget with keypad, display, and key blade.

From the Instruction Booklet

Name
Door Decoder
Description
A powerful crypto-breaker program. It cracks the code on security doors in seconds.

In Facility the security door to the bottling room is firmly locked, but thankfully our friend Dr. Doak has the solution. Once you've obtained the Door Decoder from Dr. Doak, equip it from the Pause Menu, walk up to the bottling room door, and press Z to use the decoder.

Bomb Defuser

Infinite Use
Yes
Location
Frigate
Front view. It seems to have z-fighting issues when used as a world model.

From the Instruction Booklet

Name
Bomb Defuser
Description
A device built for 007; cuts the correct wire automatically.

The player will find the Bomb Defuser in their inventory when playing Frigate. In order to use it, select it from the Pause Menu and press Z when near a bomb. Do not press B or the bomb will explode.

Camera

Infinite Use
Yes
Location
Bunker 1, Silo
Close up view of the Camera.

From the Instruction Booklet

Name
Microcamera
Description
Compact camera, with a manual zoom facility. Perfect for spying...

Is it really smart for 007 to have his number on his camera? Aren't spies supposed to be inconspicuous? Regardless, this handy camera can be zoomed in and out with and while in Aim Mode. Press Z to snap a photo. The camera has infinite film.

The game's model seems to be a mix of the Minox A/IIIs that George Lazenby's Bond uses in On Her Majesty's Secret Service and the subminiature camera Rooger Moore's Bond uses in Moonraker.

Key Analyzer

Infinite Use
Yes
Location
Bunker 1
Pause Menu view.

From the Instruction Booklet

Name
Key Analyzer
Description
Built by Q specifically to copy the GoldenEye code key.

This gadget does nothing without the GoldenEye Key. Once you have picked up the GoldenEye Key in Bunker 1, select the Key Analyzer from inventory, then press Z to copy the key.

Covert Modem

Infinite Use
No
Max Capacity
11
Location
Dam
Close up view of the model.

From the Instruction Booklet

Name
Covert Modem
Description
Ideal for gaining access to closed data storage systems. Above ground, that is.

This small device is thrown upon pressing the Z button. Once thrown you cannot retrieve it, so be sure to throw it correctly the first time!

Tracker Bug

Infinite Use
No
Max Capacity
11
Location
Frigate
Close up view of the model.

From the Instruction Booklet

Name
Tracker
Description
This magnetic tracker has a long life and a huge range. Just have to plant it carefully.

This gadget uses the same model as the Covert Modem and functions much the same way. If you miss you'll fail the objective. Where you plant it on the Pirate Helicopter does not matter. You can plant it in the most obvious spot and the Janus Syndicate won't notice it!

Datathief

Infinite Use
Yes
Location
Bunker 1
Close up view of the model.

From the Instruction Booklet

Name
Datathief
Description
A high speed, high density, data copying device. Can break through nearly all protective measures.

This is a very simple gadget. You just press Z at the mainframe in Bunker 1 after Boris enters the password and it does all the work for you.

Watch Magnet Attract

Infinite Use
No
Max Capacity
10
Location
Bunker 2, Archives
Device in the Pause Menu.

From the Instruction Booklet

Name
Watch Magnet
Description
A miniature electromagnet. Only a few uses before charge is drained completely.

This is a cool gadget that lets you pick up anything the player could normally pick up, but from a small distance away. It was inspired by Bond's magnetic watch in Live and Let Die.

Guidance Data

Infinite Use
Yes
Location
Aztec
World view of the floppy disk.

For the first bonus mission, Aztec, Q provides you with high-tech floppy disk which allows NASA to take control of the stolen Space Shuttle after it reaches orbit. Maybe I'm weird, but the inclusion of this floppy disk always gave the Aztec mission a sort of timeless feel to me. This gadget has no entry in the instruction booklet.
