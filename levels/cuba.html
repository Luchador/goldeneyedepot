Description

Cuba is a small unique stage used only for GoldenEye's credit sequence. It reuses textures and objects from Jungle. As soon as the level is loaded Action Blocks take control away from the player. A third person camera orbits around Bond and Natalya as they kiss. There is no way to walk around the stage in first person view without hacking or modding the game.

Cuba in the only stage which renders at a higher resolution than the standard 320 x 240 pixels. Cuba renders at 440 x 330 pixels, an upgrade it can get away with thanks to being so small and using little memory.

Cuba was made by taking the portion of Jungle around the second drone gun and filling in the gaps with a tree wall. When you import both Jungle and Cuba's geometry into Blender and move them on top of each other, you can see the geometry matches perfectly.

Walkaround

Cuba does have collision tiles so if we disable the Action Block that takes control away from the player we can walk around it like a normal stage. Due to Cuba rendering at a higher resolution some elements in the Pause Menu are misaligned. Cuba does not have a briefing file so the stage name reads "E R R O R" in the Pause Menu, there are no objectives, and the Background section simply reads, "NO BRIEFING FOR THIS MISSION."
